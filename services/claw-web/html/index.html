Claw Web

แอปในเบราว์เซอร์ (SPA) ที่เข้าสู่ระบบด้วย Central ID ผ่าน Login SDK

PKCE (S256) · token อยู่ในหน่วยความจำของแท็บนี้เท่านั้น ไม่เขียนลง storage

ทำงานอย่างไร

  1. SDK สร้าง PKCE (verifier + challenge S256), state และ nonce แล้วพาไปหน้า login ของ Central ID
  2. Keycloak ส่ง authorization code กลับมาที่ /auth/callback — SDK ตรวจ state และ iss ก่อนแลก code ด้วย verifier
  3. SDK ตรวจลายเซ็น id_token (RS256 จาก JWKS), aud, azp, exp และ nonce ก่อนเชื่อ claims
  4. เรียก Buyer API ผ่าน Kong ด้วย Bearer token — Kong และ Buyer ตรวจ aud=buyer-api + scope อีกชั้น
